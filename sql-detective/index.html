霞光畫廊失竊案

一幅水墨畫在閉館後消失了。你手上只有警局資料庫。不用任何基礎：第 0 關只要改一個字。之後每一關學一個 SQL 觀念，找到線索，最後指認犯人。

結案

你從「只改一個字」開始，用這些 SQL 寫法破了案：

  • SELECT *、SELECT 欄位：看資料
  • WHERE + AND：篩選條件
  • ORDER BY … DESC + LIMIT：排序、取前幾筆
  • LIKE '%字%'：模糊比對
  • JOIN … ON：用共同欄位把兩張表接起來
  • 多個 JOIN：一次串三、四張表

下一步可以試試 COUNT(*) 和 GROUP BY：例如算出每條街住了幾個人。
